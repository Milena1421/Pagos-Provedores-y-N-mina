
GUÍA DEFINITIVA PARA CONFIGURAR LA NOTIFICACIÓN DE CORREOS

Sigue estos 5 pasos en tu terminal para activar el sistema de correos y eliminar los errores:

PASO 1: Iniciar sesión en Supabase (si no lo has hecho)
> supabase login

PASO 2: Enlazar con tu proyecto (usa tu ID de proyecto: xfsbogjozqvaphoapqnz)
> supabase link --project-ref xfsbogjozqvaphoapqnz

PASO 3: Crear la carpeta de la función
> supabase functions new send-payment-email

PASO 4: Copia y pega el siguiente código en el archivo: 
./supabase/functions/send-payment-email/index.ts

-------------------------------------------------------------------------
import { serve } from "https://deno.land/std@0.168.0/http/server.ts"

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
}

serve(async (req) => {
  // Manejo de Preflight para CORS
  if (req.method === 'OPTIONS') {
    return new Response('ok', { headers: corsHeaders })
  }

  try {
    const { record, provider, to } = await req.json()
    const RESEND_API_KEY = Deno.env.get('RESEND_API_KEY')

    const res = await fetch('https://api.resend.com/emails', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${RESEND_API_KEY}`,
      },
      body: JSON.stringify({
        from: 'Ingeniería 365 <onboarding@resend.dev>',
        to: [to],
        subject: `NUEVO RADICADO: ${record.radicado} - ${provider.nombre}`,
        html: `
          <div style="font-family: sans-serif; padding: 20px; color: #333;">
            <h2 style="color: #1e40af;">Nuevo Radicado de Pago</h2>
            <hr/>
            <p><strong>Radicado:</strong> ${record.radicado}</p>
            <p><strong>Proveedor:</strong> ${provider.nombre}</p>
            <p><strong>Identificación:</strong> ${provider.identificacion}</p>
            <p><strong>Valor:</strong> $${record.valor.toLocaleString()}</p>
            <p><strong>Categoría:</strong> ${record.categoria}</p>
            <p><strong>Descripción:</strong> ${record.descripcion}</p>
            <br/>
            <a href="https://xfsbogjozqvaphoapqnz.supabase.co" 
               style="background: #1e40af; color: white; padding: 10px 20px; text-decoration: none; rounded: 5px;">
               Ver en el Sistema
            </a>
          </div>
        `,
      }),
    })

    const data = await res.json()
    return new Response(JSON.stringify(data), {
      headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      status: 200,
    })
  } catch (error) {
    return new Response(JSON.stringify({ error: error.message }), {
      headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      status: 400,
    })
  }
})
-------------------------------------------------------------------------

PASO 5: Configurar la API KEY de Resend en Supabase (SECRETO)
> supabase secrets set RESEND_API_KEY=re_tu_llave_de_resend_aqui

PASO 6: Desplegar la función
> supabase functions deploy send-payment-email

---
Una vez ejecutado el Paso 6, el error "Failed to send a request" desaparecerá y los correos llegarán instantáneamente a ${adminEmail}.
